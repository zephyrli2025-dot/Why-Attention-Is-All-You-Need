# Attention Is All You Need：学习笔记与简单复现

[English](README.md)

这个仓库是我学习论文 *Attention Is All You Need* 及 Transformer 架构时整理的学习笔记。它首先服务于我自己循序渐进地理解论文，也希望能为和我一样刚接触这一主题的同学提供一个清晰、易懂的起点。

我不想把论文当作需要背诵的结论，而是希望通过「详细笔记 + 可复现的小型代码案例」把概念落到实处。每个案例都会尽量只聚焦一个核心问题，让分词、位置编码、注意力机制、掩码，以及编码器—解码器训练等内容，都能与实际可运行、可观察的代码对应起来。

## 仓库会包含什么

- 用尽量平实的语言逐步拆解论文的学习笔记
- 说明明确、可在 CPU 上运行的小型实验
- 方便阅读、修改和动手验证的代码与数据
- 持续记录学习过程中的问题、观察与实现取舍

## 当前起点

第一个可复现实验是一个小型的词序还原任务：模型接收一个被打乱的四词句子，并学习生成语法正确的词序。任务刻意保持简单，这样我们可以不受大规模数据集干扰，专注观察序列排序、位置信息和解码器掩码的作用。

数据集的设计与生成方式请见[数据集说明](data/README.md)。

## 关于项目定位

这是一个以学习为目标的项目，而非面向生产环境的 Transformer 库。这里优先考虑清晰与可复现性：相比追求极致优化，代码会更侧重于易读、易改和便于实验。
